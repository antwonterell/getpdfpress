How to Merge Multiple PDFs Into One File

By the getPDFpress team · Updated July 21, 2026

Fast answer: Open the Merge tool, select two or more PDFs - they combine in the order you choose them - and download the single merged file. If the result must also fit an upload limit, compress it after merging, not before.

When merging is the answer

The single-file requirement is everywhere: "upload your application as one PDF," "submit statement and ID together," "combine all supporting documents." Portals impose it because one file is easier to route, review, and archive than a loose pile. Your documents, meanwhile, arrive from everywhere - a resume from Word, a certificate scanned at a library, a statement downloaded from a bank. Merging is the bridge between how documents arrive and how systems want them.

Merging also earns its keep for personal organization: one file per tax year, one file per rental application, one combined scan of a paper stack. A single well-named PDF beats eleven attachments named scan_004.pdf.

Step by step

  1. Open the Merge tool and select two or more PDFs. The selection order becomes the document order, so pick them in sequence.
  2. Run the merge. The tool copies every page from every file into one document, preserving each page's original dimensions and orientation.
  3. Check the result size shown on screen, then download. The merged file is roughly the sum of its parts.
  4. Open it once and scroll through - thirty seconds of review catches a wrong order or an unexpected blank page before a recipient does.

Getting the order right

Order mistakes are the most common merge problem, and they are preventable. Decide the reading order before selecting files: typically the primary document first (application, resume, cover letter), supporting evidence after, in the sequence the reviewer will want it. If you selected files in the wrong order, just run the merge again - it takes seconds, and redoing it beats sending a jumbled document.

For complex assemblies - interleaving pages from different sources, dropping specific pages - combine tools: Split the sources into individual pages first, then merge exactly the pages you want in exactly the order you want. Split and merge together form a complete page-level editor.

Keeping the merged file small

Merged files inherit their parents' weight, and a merge of scans can cross upload limits fast. Three rules keep sizes sane:

Merge first, compress second. Compression optimizes the whole file's structure; doing it before merging wastes part of that work when the merge rewrites the container. The efficient pipeline is: assemble everything, then one pass through the compressor aimed at your limit.

Include only required pages. Every extra page spends byte budget. If the form wants three documents, merge those three - not the whole folder.

Mind the mixed-source problem. A merge of one digital document and one heavy scan is dominated by the scan. If the merged file misses a limit, the scan pages are where the size lives - consider rescanning them smaller before re-merging, per the too-large guide.

Frequently asked questions

Is there a limit on how many PDFs I can merge?

The tool accepts up to 20 files per merge, 25MB each. For bigger jobs, merge in batches - combine the first set, then merge that result with the next set.

Will merging change the quality of my pages?

No. Merging copies pages as they are, without recompressing images or altering content. Size and quality changes only happen if you separately compress the merged file.

Can I rearrange pages after merging?

Run the result through the Split tool to break it into pages, then merge the pages in the new order. For a fresh merge, simply redo it selecting files in the right sequence.

Do password-protected PDFs merge?

Encrypted files generally fail to merge without the password. Remove protection with the password first in your PDF reader, or provide an unprotected copy.
