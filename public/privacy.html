Privacy Policy

getPDFpress processes uploaded files on our server to provide PDF tools. Temporary files are stored only as long as needed for processing and automatic cleanup runs regularly.

Uploaded files

Do not upload documents you are not authorized to process. We do not sell uploaded files. Processing may use server-side libraries and, for some conversion tools, ConvertAPI when configured.

Advertising and analytics

This site uses Google Analytics 4 to understand aggregate usage: which pages are visited, which tools are used, and roughly where visitors come from. Analytics uses cookies and collects standard technical data such as browser type and anonymized IP address. It never receives the contents or names of files you process. You can block analytics with standard browser tools or extensions and every tool on this site will continue to work normally.

Advertising is not currently enabled. If ads are added in the future, this policy will be updated first to describe the ad provider and any additional data collection.
